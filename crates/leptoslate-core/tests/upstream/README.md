# Upstream Slate fixtures

These fixtures replay test cases from [Slate](https://github.com/ianstormtaylor/slate)'s
own suite against `leptoslate-core`.

They are generated JSON, not hand-written Rust tests. The runner is
[`../upstream.rs`](../upstream.rs).

## Known failures

Known divergences live in [`known-failures.json`](known-failures.json). Each
entry has the upstream source path and a written reason. The runner groups the
reasons in its output.

The list is deliberately strict: if a known failure starts passing, the test
fails until the entry is removed. Add a new entry only after deciding that the
divergence is a deliberate gap rather than a bug to fix now. Set
`UPSTREAM_INCLUDE_KNOWN=1` while working on a gap to print the actual mismatch
even for known failures.

Fixtures whose *call shape* is not supported yet (for example `match`
predicates, `unit: 'line'`, or `voids` options) are not listed individually.
The runner reports them as `unsupported` with a grouped reason and does not
count them as failures.

The largest current gaps are:

- Void/read-only, non-selectable and cross-block deletion edge cases (24).
- A handful of backward `wrapNodes`/`unwrapNodes` split-inline cases (6).
- Custom `match`/`merge` functions and schema fallback normalizers are
  reported as unsupported rather than emulated.
- Arbitrary selection properties (`set_selection` operations) are unsupported.

## Regenerating

From the repository root:

```bash
cd scripts/upstream-fixtures
npm ci
npm run extract
```

The extractor downloads the pinned Slate tarball into
`~/.cache/leptoslate-upstream`, evaluates the requested fixtures with `tsx`,
and rewrites `fixtures/` plus `skipped.json`. Only generated JSON is committed,
so `cargo test` never needs Node or the network.

To target another upstream commit:

```bash
UPSTREAM_SHA=<sha> npm run extract
```

## Adding the next phases

Extend `CATEGORIES` in `scripts/upstream-fixtures/extract.ts`, then add the
matching call mappings in `../upstream.rs` (interfaces) or rely on the existing
